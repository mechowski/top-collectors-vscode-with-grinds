# Топ сборщиков — VS Code

Готовый проект сайта-лидерборда.

## Запуск

1. Распакуйте проект.
2. Откройте папку `top-collectors-vscode` в VS Code.
3. Установите расширение **Live Server** (если VS Code предложит).
4. Откройте `index.html`.
5. Нажмите **Go Live** в правом нижнем углу VS Code.
6. Вставьте ссылку на базу «Сборка ИМ» и, при необходимости, отдельную ссылку на базу «Сборка МП».
7. Нажмите **Загрузить**.
8. Выберите:
   - столбец с фамилией;
    - столбец со статусом;
    - столбец с помолами.

Важно: открывайте сайт через **Live Server** (`http://localhost:...`), а не двойным кликом по `index.html`. Это необходимо браузеру для безопасной загрузки данных Google Таблицы.

Настройки подключения таблицы и список источников доступны после входа администратора. Используйте логин `admin` и пароль `1234`. Вход запоминается в браузере; для сброса сохранённого входа нажмите «Выйти». Это клиентское ограничение интерфейса, не замена серверной авторизации.

Листы для статистики должны называться датами. В поле «Формат названия листов» укажите шаблон даты. По умолчанию используется формат `DD.MM.YYYY`.

Сайт автоматически загружает:

- сегодняшний лист — статистика за день;
- листы с понедельника текущей недели по сегодня — статистика за текущую неделю;
- листы за сегодня и предыдущие 29 дней — статистика за 30 дней.

Например, для формата `DD.MM.YYYY` лист за 25 августа 2026 года должен называться `25.08.2026`. Сайт сначала загружает всю базу ИМ в формате XLSX и получает из файла реальные названия листов, поэтому несуществующие листы не учитываются. База МП загружается отдельно и необязательна: если ссылка не указана или база недоступна, статистика ИМ продолжит работать. Обе указанные ссылки сохраняются в браузере.

## Статистика по отдельной вкладке

В админском блоке «Статистика по вкладке» можно вставить ссылку на конкретную вкладку Google Таблицы. Ссылка должна содержать `gid`, например `.../edit#gid=123456`.

После загрузки вкладки выберите столбцы «Сборщик» и «Статус». Сайт посчитает количество непустых позиций для каждого сборщика и покажет статусы, которые встречаются в его строках. Ссылка на вкладку сохраняется в браузере.

## Как работает подсчёт

Рейтинг «Сборка ИМ» не учитывает строки `ОЗОН ФБС`, `ВБ ФБС` и `ЯНДЕКС ФБС`. Они выводятся только в отдельном блоке «Сборка МП».

В «Сборка МП» каждый дневной лист проверяется отдельно. Учитываются только строки с точными названиями `ОЗОН ФБС`, `ВБ ФБС` и `ЯНДЕКС ФБС`; затем показатели одноимённых строк складываются за выбранный период. Регистр и лишние пробелы не влияют на совпадение.

Источник «Сборка МП» — отдельный лист `ОПТ и МП`. Если такого листа нет в реально загруженной Google Таблице, МП-статистика не рассчитывается и показывает нулевой результат.

Для периодов 7 и 30 дней каждый найденный лист сначала считается отдельно, затем результаты складываются по фамилии. Если лист за дату отсутствует или в строке нет нужного значения, его вклад равен нулю.

Сайт проходит по всем строкам Google Таблицы.

Для каждой фамилии:
- `Статус = Собран` → +1 к счётчику «Собран».
- `Статус = Помоло` или `Помол` → +1 к счётчику «Помолы».
- остальные статусы не учитываются.

Например:

| Фамилия | Статус |
|---|---|
| Иванов | Собран |
| Иванов | Собран |
| Петров | Собран |
| Иванов | Помоло |

Результат:

- Иванов — 2
- Петров — 1

## Google Таблица

Для текущей браузерной версии таблица должна быть доступна для просмотра по ссылке.

Если таблица закрытая, для production-версии рекомендуется сделать backend через Google Sheets API, чтобы не раскрывать ключи/учётные данные в браузере.

## Сортировка рейтинга

Сначала сотрудники сортируются по количеству «Собран».
Если количество «Собран» одинаковое — выше сотрудник с большим количеством «Помолов».
