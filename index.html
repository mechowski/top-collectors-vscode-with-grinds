Топ сборщиков

Рейтинг рассчитывается автоматически из Google Таблицы

Настройки «Сборка ИМ»

Формат даты задаётся в поле выше. Каждый непустой помол считается отдельно. Для «Сборка МП» ежедневно учитываются только одноимённые строки ОЗОН ФБС, ВБ ФБС и ЯНДЕКС ФБС.

Настройки «Сборка МП»

Для МП используется только лист «ОПТ и МП». В расчёт попадают строки ОЗОН ФБС, ВБ ФБС и ЯНДЕКС ФБС.

Настройки «ОПТ»

ОПТ берёт строки из вкладки «ОПТ и МП». Для разделения по дням выберите столбец с датой: дата может быть внутри текста, но должна быть в формате ДД.ММ.ГГГГ, ДД/ММ/ГГГГ или ДД-ММ-ГГГГ.
